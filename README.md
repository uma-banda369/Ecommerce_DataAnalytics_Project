# Sales-Dashboard
Data analysis on sales 

**Project Overview**
This project analyzes sales transaction data to identify revenue trends, product performance, regional performance, customer behavior, and key business KPIs.
The objective was to transform raw sales data into meaningful insights and an interactive Power BI dashboard that can support business decision-making

**Tools & Technologies**
•	SQL
•	Microsoft Excel
•	Power Query
•	Power BI
•	DAX

**Key Analysis**
•	Monthly and yearly revenue trends
•	Sales and profit performance
•	Product category analysis
•	Regional performance
•	Customer segment analysis
•	Average order value
•	Year-over-year growth
•	Identification of underperforming segments
