# E-Commerce Sales & Profit Analysis

## Project Overview

This project analyzes e-commerce sales data using Microsoft Excel
to understand sales performance, profitability, customer behavior,
regional performance and discount impact.

## Business Questions

#Sales
What is total sales?
What is monthly sales trend?
Which category generates highest sales?
Which region generates highest sales?
#Profit
What is total profit?
Which category generates highest profit?
Which products have negative profit?
Which region has highest profit?
#Customers
Who are the top customers?
How many customers/orders are there?
#Discounts
Which discount range generates highest sales?
Which discount range generates highest profit?
Is higher discount associated with lower profit?
#Business
Which products should receive more attention?
Where should the company investigate poor performance?
